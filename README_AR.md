# منظومة البيع — مشروع Android قابل للبناء

هذا مشروع Android Studio يغلّف ملفات منظومة البيع الحالية داخل تطبيق Android باستخدام WebView، ويحمّل الواجهة من ملفات محلية حتى لا يحتاج إلى الإنترنت لفتحها.

## بناء APK
1. نزّل وثبّت Android Studio على كمبيوتر.
2. افتح Android Studio ثم اختر **Open** وحدد مجلد `pos_android_project`.
3. انتظر اكتمال Gradle Sync. يلزم تثبيت Android SDK Platform 35 وAndroid Gradle Plugin المتوافق.
4. من القائمة اختر **Build > Build APK(s)**.
5. بعد نجاح البناء ستجد الملف عادة في:
   `app/build/outputs/apk/debug/app-debug.apk`
6. انقل APK إلى الهاتف، وافتحه، واسمح بالتثبيت من هذا المصدر عند طلب Android ذلك.

## ملاحظات
- هذا أرشيف مصدر Android وليس ملف APK جاهزًا.
- لم يمكن بناء APK داخل بيئة الإنشاء الحالية لعدم توفر Android SDK وGradle.
- يستخدم التخزين الذي توفره واجهة الويب (مثل localStorage)؛ لا يحتوي بعد على SQLite.
- لم تُختبر الطباعة الحرارية أو Bluetooth أو تعدد المستخدمين.
- قبل استخدامه تجاريًا، اختبر كل عمليات البيع والمرتجعات والنسخ الاحتياطي على جهاز فعلي.
